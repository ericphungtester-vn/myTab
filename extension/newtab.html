myTab

Guide

  1. Add myTab from the Chrome Web Store.
  2. If your browser's home page/new tab is locked to something else and won't switch to myTab automatically (e.g. set by a workplace policy), you can still open myTab directly at: chrome-extension://faoejkfojflndmknhenfjecinppdemai/newtab.html — bookmark that URL, or paste it into Settings → On startup/Home button as a custom page, for one-click access.

Use the Columns slider in Settings to set 1–14 columns.

Paging: if the window isn't wide enough to show every column at once, ‹ / › buttons appear next to the "Chrome Bookmarks" heading to page through them, with a page counter between them. Since "Your Bookmarks" shares the same column layout, it pages in sync with these same buttons. They're hidden whenever everything already fits, while searching, or when there are no bookmarks. Resizing the window recalculates how many columns fit and re-pages automatically. While dragging a folder, bookmark, or a whole column, drag it near the left/right edge to auto-scroll to the next/previous page — so it can be dropped on a column that isn't on the current page. A horizontal trackpad/mouse-wheel scroll also pages through the columns directly, without needing the ‹ › buttons.

Default order within each column and inside every folder: folders A–Z first, then bookmark items A–Z.

Auto-expand: if a column contains only one root folder, it expands automatically. If there are two or more root folders, all start collapsed — click a folder header to expand it. Expand/collapse state is saved and restored on next open.

Auto-expand subfolders: toggle in Settings to control whether nested folders (level 2 and deeper) start expanded or collapsed by default.

Folder count: each folder header shows a small badge with the number of items directly inside it.

Your Bookmarks: a collapsible "Your Bookmarks" section appears above the Chrome bookmark columns. It contains all your custom folders (the blue ones) and can also hold real bookmarks — stored separately from Chrome's own bookmarks. Click the header to collapse or expand it. Click + in the header to create a new custom folder (this button is always there, even in an empty column).

Adding a real bookmark to Your Bookmarks: drag a bookmark from the Chrome Bookmarks columns and drop it onto a custom folder (or empty space in a Your Bookmarks column, to add it at the top level). Each added item shows a small × button to remove it — this only removes it from Your Bookmarks, never from Chrome's actual bookmarks.

Search looks across both Chrome Bookmarks and Your Bookmarks at once.

Column order: drag the ⠿ grip at the top-left of any column to move that column to a different position. A blue line appears on the left or right edge of the target column to show where it will land.

Column assignment

  • Drag a folder header or bookmark item to a different column to assign it there.
  • A child with no explicit assignment follows its parent — move the parent and the child comes along.
  • Assign a child to a different column to split it out independently — the parent stays where it is.
  • Reducing columns moves items in removed columns to the nearest left column.

Reordering within a column or folder

  • Drag any folder or bookmark item and hover over another item in the same column or inside the same folder — a blue line appears above or below to show where it will land.
  • Custom order is saved and restored on next open.

Moving an item into a different folder

  • Drag a bookmark or folder and drop it directly on another folder's header (not the gaps between rows) — a dashed outline appears while hovering to show it will go inside. It's added at the end of that folder's contents; drag it again afterward to reorder within.
  • This only changes how it's displayed in myTab — its real Chrome bookmark is never moved (chrome.bookmarks.move() is never called). Items shown this way get a dashed blue left edge and a tooltip noting they aren't really moved in Chrome.
  • Drag it back out to a column's root to clear this and return it to its real position/column.
  • A folder can't be dropped into itself or into one of its own subfolders — rejected with a toast.

Custom folders

  • Click the + button in the Your Bookmarks header to create a new custom folder. Custom folders have a blue icon to distinguish them from Chrome bookmark folders (which use a yellow icon).
  • The folder opens automatically so you can see a note reminding you it is not stored in Chrome bookmarks.
  • Double-click the folder name to rename it — once renamed, the note disappears and the folder behaves like any other folder.
  • Right-click a custom folder for options: Open all in new tabs, New subfolder, Delete folder. Open all in new tabs opens every bookmark in the folder and automatically groups them into a named tab group (group name = folder name). New subfolder creates a nested folder directly inside the current one — nesting is unlimited and follows the hierarchy. Delete folder shows a confirmation first (this data only exists in Your Bookmarks, so deleting it can't be undone by looking in Chrome's own bookmark manager) — deleting also deletes all its subfolders and any bookmarks added to it.

Opening bookmarks

  • Left-click a bookmark to open it in a new tab.
  • Middle-click (scroll-wheel click) to open in a new tab.
  • Right-click a bookmark item for options: Open in new tab, Open in current tab, Copy URL, Copy title, Rename, Delete. Rename and Delete act directly on Chrome Bookmarks and show a warning dialog with a "Don't ask again" checkbox.
  • Right-click a folder for options: Open all in new tabs, New subfolder, Rename, Delete folder. Open all in new tabs opens every bookmark in the folder and automatically groups them into a named tab group (group name = folder name). Rename and Delete show a warning dialog with a "Don't ask again" checkbox — check it to skip the warning on future actions.
  • Dialog language: every warning dialog (rename, delete, Reset Quick Bar) has a small EN/VI button in its top-right corner — click it to switch that dialog's text between English and Vietnamese. The choice is remembered for every future dialog and syncs across devices. The rest of the app's UI stays English-only for now.

Keyboard

  • Press / anywhere on the page to jump to the search box.
  • Press Escape inside the search box to clear the search and return to the column view.
  • Use ↑ / ↓ arrow keys to move between bookmark items. Press Enter to open the focused bookmark in a new tab.

Zoom: use the Zoom slider in Settings (70%–130%) to scale the bookmark content up or down.

Scrolling: hover over a column and scroll with the mouse wheel or trackpad. The scrollbar is hidden to keep the layout clean. The ⠿ and + buttons at the top of each column stay fixed while scrolling.

Reset: use Reset layout in Settings to clear all column assignments, custom ordering, and saved collapse state.

None of this changes your actual Chrome bookmark structure.

A row of pinned bookmarks and folders just below the header — visible on every tab (Bookmarks, FlashPaint), not only while browsing Bookmarks.

Pinning: right-click any bookmark or folder in the main list and choose Pin to Quick Bar. Right-click an already-pinned item directly in the bar to get the same menu, now showing Unpin from Quick Bar — no need to go find the original bookmark again.

Opening items: click a pinned bookmark to open it in a new tab. Click a pinned folder (shown with a folder icon and a small ▾) to open a dropdown of its contents — click a subfolder inside to drill into it (a ‹ Back row appears at the top to go back up); click a bookmark inside to open it and close the dropdown.

When pinned items don't fit on one row: a ▾ button appears at the end of the bar — click it to expand the bar onto as many rows as needed so every pinned item is visible at once. Click the button again (now ▴) to collapse back to a single scrollable row. This expanded/collapsed state is remembered across reloads, and re-adjusts automatically if you resize the window.

Limit: up to 37 pinned items. Trying to pin more shows a toast message and the item is not pinned — unpin something first to make room.

⟲ Reset: the last button in the bar — unpins everything in one click and shows a confirmation toast. There's no undo, but nothing is deleted from your actual bookmarks; you can always pin things again.

Pinned items and their order sync via Chrome Sync, the same as your other settings.

Open the Settings panel by clicking the ⚙ icon in the top-right corner.

Bookmark list

  • Columns — sets the number of columns displayed (1–14). Click ↺ to reset to 1.
  • Item spacing — adjusts the vertical gap between bookmark items (0–24 px).
  • Zoom — scales the entire bookmark area (70%–130%). Click ↺ to reset to 100%.
  • Auto-expand subfolders — when on, nested folders (level 2 and deeper) start expanded; when off they start collapsed.
  • Folder name color — pick a custom color for folder names. Click ↺ to reset to default.
  • Item name color — pick a custom color for bookmark titles. Click ↺ to reset to default.
  • Column background — set a background color for each column. Click ↺ to remove the color (transparent). Reset layout also clears this.
  • Column bar background — set a background color for the sticky bar (⠿ + buttons) at the top of each column. Click ↺ to remove the color (uses frosted-glass default). Reset layout also clears this.

Tab behavior

  • Auto-group tabs — when on, "Open all in new tabs" automatically groups all opened tabs into a named tab group (group name = folder name); when off, tabs open without grouping. Default: on.
  • Open all mode — controls which bookmarks are collected when using "Open all in new tabs":
    • All in one group — opens every bookmark in the folder and all its subfolders recursively, grouped into one tab group.
    • Per subfolder — direct items in the folder form one group, and each subfolder forms its own separate tab group named after it.
    • Direct items only — opens only the bookmarks directly inside the folder; subfolders are ignored.

Font

  • Family — choose the typeface for folder names and bookmark titles (System default, Arial, Verdana, Trebuchet MS, Georgia, Courier New). Click ↺ to reset to System default.
  • Size — text size from 10 px to 16 px. Click ↺ to reset to 12 px.
  • Weight — thickness from Thin (100) to Heavy (900). Click ↺ to reset to Medium (500).
  • Italic — toggle italic style on or off.

Background

  • Color — sets the page background color. Click ↺ to reset.
  • Image URL — paste a direct image link and press Enter. The URL must point directly to an image file (typically ending in .jpg, .png, .webp). Click ✕ to remove.
    Tip: right-click an image in Chrome → "Open image in new tab" → copy the URL from the address bar. Recommended sources: Unsplash (images.unsplash.com/…), Imgur (i.imgur.com/…). Many sites block direct image linking — if loading fails, a message appears below the input.
  • Image size — Cover (fills the page), Contain (fits inside), Original (natural size), or Custom — reveals Width and Height sliders (10–300%) to set exact dimensions independently.
  • Position — drag the dot inside the pad to move the background image around the page.
  • Blur — apply a blur effect to the background image (0–20 px). Click ↺ to reset to 0.
  • Opacity — controls the transparency of the background image (0% = invisible, 100% = fully visible). Click ↺ to reset to 100%. Useful combined with a solid background color for a subtle watermark effect.
  • Tint color + Tint opacity — overlay a semi-transparent color on top of the image to tone or darken it. Click ↺ to reset each to its default. Set opacity to 0 to disable the tint.

Reset layout

Clears all column assignments, custom ordering, and folder order — restores the default layout. Font, background, and zoom settings are not affected.

FlashPaint

  • Save location — by default, Export PNG and Save Project use the browser's normal download behavior. Click Change to pick a folder instead — from then on, both write straight into it with no download prompt. The chosen folder is remembered across restarts; click ↺ to go back to the default download behavior. If writing to the chosen folder ever fails (folder moved, permission revoked), that save falls back to a normal download and a toast explains why.

All your data is saved to Chrome Sync and tied to your Google account.

This includes:

  • Custom folders (created with +)
  • Column layout, ordering, and assignments
  • Settings (spacing, number of columns)

Sign in to Chrome with the same Google account on another computer — everything loads automatically.

Note: Chrome Sync has a 100 KB storage limit. This is sufficient for typical use.

  1. Open Chrome and go to chrome://extensions/
  2. Enable Developer mode (top right)
  3. Click Load unpacked → select the /extension/ folder
  1. Create a Chrome Developer account at developer.chrome.com ($5 one-time)
  2. Zip the contents of the extension folder, not the folder itself — manifest.json must sit at the zip's root or the upload is rejected: cd extension && zip -r ../meTab.zip . -x '*.DS_Store'
  3. Before submitting for the first time, set and verify a publisher contact email — Dashboard's account-level ☰ menu → Settings (not the item's own Settings/Privacy tabs). Submit is blocked until this email is verified via the link Google emails you.
  4. On the item's Privacy tab: "Are you using remote code?" → No (everything ships in the package; loading a favicon image from google.com doesn't count — only remote JS/Wasm does). Under "Data usage", only Website content applies (bookmarks + clipboard image/text) — check all 3 "I certify" boxes. See CHROME_STORE_LISTING.md at the repo root for drafted single-purpose/permission-justification text ready to paste in.
  5. Privacy policy URL must be genuinely public — a link into a private GitHub repo returns 404 for Chrome's crawler even though it works fine for you while logged in. If the repo is private, host just PRIVACY_POLICY.md's content as its own public GitHub Gist (or similar) instead.
  6. Distribution visibility: Unlisted is the better default for a personal tool — installable by anyone with the link, but not shown in Web Store search, and reviewed less strictly than Public.
  7. Upload the zip at the Developer Dashboard (https://chrome.google.com/webstore/devconsole/) → select the myTab item → Package tab → Upload new package, add description & screenshots (1280×800 or 640×400, up to 5), submit for review — 1–3 days typically, but the bookmarks permission triggers stricter review and can take longer

Updating after code changes: code changes don't push automatically. Bump the version in manifest.json, re-zip, and upload the new package at https://chrome.google.com/webstore/devconsole/ for review. Once approved, Chrome auto-updates it on users' machines within a few hours to a day.

Locally loaded (unpacked) extensions never auto-update — reload manually at chrome://extensions/ after each change.
