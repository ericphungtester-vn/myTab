Language: English (default), Tiếng Việt, Español, Français, Deutsch, Italiano, Português, 中文, 日本語, 한국어, Русский, العربية, Ελληνικά, עברית, हिन्दी, ไทย, or classic Lorem Ipsum (Latin) — each uses a themeless bank of common words, not real sentences. Chinese, Japanese, and Thai are joined with no spaces (as normally written); the word counter below the output box counts by whitespace, so it won't be meaningful for generated text in those three — the character counter is still exact for every language. Arabic and Hebrew display right-to-left automatically. Hidden entirely when Unit is Strings, since Strings has nothing to do with any language.

Not every non-Latin script is covered — this list is scoped to ones with word banks I'm confident are accurate (not fabricated). Ask if you want another script added (e.g. Georgian, Armenian, Khmer, Lao, Sinhala, Tibetan, Mongolian, Amharic, Burmese).

Unit — pick one, and "Amount" is measured in that unit (switching units resets Amount to that unit's own default and regenerates immediately):

  • Characters (default Amount 1) — one continuous piece of exactly that many characters, cut from the Language's word bank.
  • Words (default 1) — exactly that many words, raw (no capitalization or trailing punctuation).
  • Sentences (default 1) — that many sentences, each a random 6–14 words with capitalization and punctuation, flowing together as one piece (not one per paragraph).
  • Paragraphs (default 2) — that many separate paragraphs, each built to the "Chars/paragraph" length (including its trailing punctuation mark), joined using "Line break": no blank line, or with a blank line between paragraphs (default).
  • Strings (default 16) — see below.

Strings is unrelated to Language and its word banks — it generates a random string of exactly "Amount" characters from the checked classes: ABC uppercase, abc lowercase, 123 digits, #$& symbols (all 32 standard keyboard symbols), and Space — like a password/random-string generator. Space defaults off; the other 4 default on with every character enabled (95 characters total). Click a class's text label (not its checkbox) to open a picker and enable/disable individual characters within that class — Space has only one character, so it has no picker.

Every checked class is guaranteed at least one character in the result (the rest fill in randomly across all checked classes) — like a real password generator, not a flat character soup. This means Amount must be at least as large as the number of checked classes (e.g. 5 classes checked needs Amount ≥ 5); Generate shows an inline error instead of running if that's not met, or if every class/character is unchecked.

Output box: click Generate to fill it, or paste your own text in — the counters below (characters, words, sentences, paragraphs, lines, spaces) always reflect whatever is currently in the box, whether generated or pasted. Sentences are split on . ! ? (and 。！？। for CJK/Hindi text); paragraphs are blocks separated by a blank line, or if there's no blank line anywhere, each non-empty line counts as one paragraph; spaces counts all whitespace (spaces, tabs, line breaks). Uncheck Count spaces to exclude whitespace from the character count. Click the copy icon in the corner of the box to copy it to the clipboard.

⟲ Reset (next to "Text" in the left sidebar): restores every setting on this tool back to its default (English, Characters, Amount 1, etc.) and regenerates immediately.

Your last-used settings — including which individual characters are enabled per class — are remembered via Chrome Sync.

Generates a real, valid file of the format and size you specify, then downloads it immediately — useful for testing upload limits, storage quotas, or just needing a file of a certain size.

Type: Plain Text, CSV, JSON, HTML, XML, Markdown, and Random Binary have no minimum size. Every other type is a genuine file of that format (a real image/archive/document, not just renamed bytes) — each has a small minimum size, since a valid file of that format can't be smaller than its own header/structure. Generate shows an inline error instead of running if you go below it.

Excel / Word / PowerPoint / EPUB (.xlsx/.docx/.pptx/.epub) are Office Open XML / EPUB files — really just a ZIP of small XML parts — that open correctly in their respective apps (and EPUB readers). The extra size beyond the minimal structure is filler text placed in cell A1 (Excel), the first paragraph (Word), the first slide's text box (PowerPoint), or the first chapter (EPUB) — it's the only thing that changes as you increase the size.

PNG / BMP / GIF / JPEG / TIFF / ICO render a real gradient/pattern image (not a solid color), with pixel dimensions that scale up with the requested size — up to a cap of 256x256, so the image stays clearly visible without needing to zoom (ICO wraps a real PNG, so it scales the same way). SVG draws a real gradient rectangle plus visible filler text, scaling by text length rather than pixel count. Sizes beyond what the image needs are simply extra bytes appended past the image data, which viewers ignore.

Every format shows or plays back something real when opened, not a blank/silent shell: HTML and XML put the filler text where it's actually rendered (not in a comment), PDF draws it as real text on the page, and WAV is an audible 440 Hz tone rather than silence.

Size: enter an amount and pick B / KB / MB. Capped at 50 MB to avoid freezing the popup.

KB/MB means: macOS Finder and Windows Explorer disagree on what "KB"/"MB" means — Finder divides by 1000 (the actual SI definition), Explorer divides by 1024 despite using the same labels. No single file size reads as a clean round number on both, so pick whichever OS you'll be viewing the file's size on; the "actual size" shown after Generate is computed the same way.

Filename: name for the downloaded file — the correct extension is added automatically based on Type.

After Generate & Download, the actual byte size produced is shown below the button — it matches your requested size exactly for every format (once above its minimum).
